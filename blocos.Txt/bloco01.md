## Bloco 1: Operações Matemáticas
  ### - QUESTÃO 01: (../src/bloco01/Questao01.java)
    Declare int a = 17 e int b = 5. Calcule e exiba: soma, subtração, multiplicação, 
    divisão inteira, divisão real (cast para double) e resto da divisão(%).

  ### - QUESTÃO 02: (../src/bloco01/Questao02.java)
    Declare double raio = 7.5. Calcule e exiba a área e a circunferência do círculo 
    com 2 casas decimais. Use Math.PI.
      * área = π * r^2 
      * circunferência = 2 * π * r

  ### - QUESTÃO 03: (../src/bloco01/Questao03.java)
    Dados os lados a = 6.0, b = 8.0, c = 10.0. Calcule e exiba o perímetro e a 
    área usando a fórmula de Herão. Use Math.sqrt().
      * s = (a + b + c) / 2 
      * área = √s(s−a)(s−b)(s−c)

  ### - QUESTÃO 04: (../src/bloco01/Questao04.java)
    Declare peso = 72.0kg e altura = 1.75m. Calcule e exiba o IMC com 2 casas 
    decimais. Não classifique ainda (isso será feito na Seção III).
      * IMC = peso / altura^2

  ### - QUESTÃO 05: (../src/bloco01/Questao05.java)
    Declare as notas: n1 = 7.5, n2 = 8.0, n3 = 6.5, n4 = 9.0. Calcule: 
      * Média aritmética: (n1 + n2 + n3 + n4) / 4
      * Média ponderada com pesos 1, 2, 3 e 4: (n1*1 + n2*2 + n3*3 + n4*4) / 10

  ### - QUESTÃO 06: (../src/bloco01/Questao06.java)
    Dados a = 1.0, b = -5.0, c = 6.0. Calcule e exiba o discriminante ∆ = b^2 − 4ac. 
    Não calcule as raízes ainda (isso será feito na Seção III).

  ### - QUESTÃO 07: (../src/bloco01/Questao07.java)
    Declare salario = 3200.0 e percentual = 8.5. Calcule e exiba: o valor do 
    aumento, o novo salário e a diferença entre o novo e o antigo.

  ### - QUESTÃO 08: (../src/bloco01/Questao08.java)
    Declare base = 3 e expoente = 5. Calcule e exiba usando Math.pow(): 
      * baseˆexpoente
      * o quadrado de base (baseˆ2) 
      * o cubo de base (baseˆ3)
    Converta cada resultado para int ao exibir.
